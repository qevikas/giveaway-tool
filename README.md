# Giveaway Tool

A lightweight utility built with **C#**, **HTML**, **CSS**, and **JavaScript** designed to manage YouTube giveaways.
It features a built-in **CommentPicker** module to seamlessly fetch comments and randomly select winners from any YouTube video via the YouTube API.

---

## 🚀 Features

*   **YouTube Comment Picker Module:** Integrates with the YouTube Data API to fetch video comments and fairly select random giveaway winners.
*   **Custom UI Settings:** Interactive frontend built with HTML, CSS, and JavaScript for smooth configuration of YouTube API client settings and parameters.
*   **API Configuration:** Securely handles request management for pulling live video engagement data.

## ⚙️ Getting Started

### Prerequisites

*   .NET SDK installed on your machine.
*   A valid **YouTube Data API Key** from the Google Cloud Console.
